# Bundesliga Match Predictor

Прогнозирование результатов матчей Бундеслиги с помощью машинного обучения (Random Forest).

## Описание

Проект обучает модель `RandomForestRegressor` на исторических данных Бундеслиги (сезоны 1993/94 — 2026/27) и предсказывает счёт предстоящих матчей на основе команд-хозяев и команд-гостей.

## Данные

- **kaggle/input/** — CSV-файлы с историческими результатами матчей Бундеслиги за сезоны 93-94 — 25-26 (источник: [Kaggle](https://www.kaggle.com/datasets/rohanrao/german-bundesliga-18912019) для сезонов 93-94 — 21-22, [football-data.co.uk](https://football-data.co.uk) для сезонов 22-23 — 25-26).
- **results.py** — результаты 9 туров сезона 26/27 (данные перенесены из CSV).
- **match_days.py** — расписание матчей сезона 23/24 (34 тура) и 26/27 (полный календарь 34 туров, источник: [sports.ru](https://www.sports.ru/football/tournament/bundesliga/calendar/)).

|---------|----------|
| `HomeTeam` | Команда хозяев |
| `AwayTeam` | Команда гостей |
| `FTHG` | Голы хозяев (полный матч) |
| `FTAG` | Голы гостей (полный матч) |
| `HTHG` | Голы хозяев (первый тайм) |
| `HTAG` | Голы гостей (первый тайм) |
| `FTR` | Итоговый результат (H/A/D) |
| `HTR` | Результат первого тайма (H/A/D) |

## Как это работает

1. Загрузка и объединение всех CSV-файлов из `kaggle/input/`.
2. Добавление фактических результатов 9 туров сезона 26/27 из `results.py`.
3. Предобработка: отбор признаков, кодирование названий команд (`LabelEncoder`), взвешивание образцов по дате (экспоненциальное затухание с коэффициентом `0.98`).
4. Разделение на обучающую и тестовую выборки (80/20).
5. Обучение `RandomForestRegressor` (1000 деревьев).
6. Оценка модели: MAE и R² на тестовой выборке.
7. Предсказание счёта для матчей тура 10 сезона 26/27 из `match_days_2627` в `match_days.py`.

## Метрики модели

При оценке качества предсказаний используются две метрики:

| Метрика | Описание | Идеальное значение |
|---------|----------|-------------------|
| **MAE** (Mean Absolute Error) | Среднее абсолютное отклонение предсказанного счёта от фактического. Показывает, на сколько голов в среднем ошибается модель. | 0 (чем меньше, тем лучше) |
| **R²** (R-squared) | Коэффициент детерминации — доля дисперсии фактических результатов, объяснённая моделью. R² = 0 означает, что модель не лучше простого предсказания среднего значения. R² < 0 — модель хуже базового уровня. | 1 (чем ближе к 1, тем лучше) |

> **Примечание:** предсказание точного счёта в футболе — сложная задача из-за высокой случайности. Даже лучшие модели в индустрии редко достигают R² > 0.3 для точного счёта.
