# Bundesliga Match Predictor

Прогнозирование результатов матчей Бундеслиги с помощью машинного обучения (Random Forest).

## Описание

Проект обучает модель `RandomForestClassifier` на исторических данных Бундеслиги (сезоны 1993/94 — 2026/27) и предсказывает результат предстоящих матчей: победа хозяев (H), ничья (D) или победа гостей (A), вместе с вероятностями каждого исхода.

## Данные

- **kaggle/input/** — CSV-файлы с историческими результатами матчей Бундеслиги за сезоны 93-94 — 25-26 (источник: [Kaggle](https://www.kaggle.com/datasets/rohanrao/german-bundesliga-18912019) для сезонов 93-94 — 21-22, [football-data.co.uk](https://football-data.co.uk) для сезонов 22-23 — 25-26).
- **results.py** — результаты завершённых туров сезона 26/27 (данные перенесены из CSV).
- **match_days.py** — расписание матчей сезона 23/24 (34 тура) и 26/27 (полный календарь 34 туров, источник: [sports.ru](https://www.sports.ru/football/tournament/bundesliga/calendar/)).

## Используемые признаки

| Признак | Описание |
|---------|----------|
| `HomeTeam` | Команда хозяев |
| `AwayTeam` | Команда гостей |
| `FTHG` | Голы хозяев (полный матч) |
| `FTAG` | Голы гостей (полный матч) |
| `HTHG` | Голы хозяев (первый тайм) |
| `HTAG` | Голы гостей (первый тайм) |
| `FTR` | Итоговый результат (H/A/D) |
| `HTR` | Результат первого тайма (H/A/D) |

## Как это работает

1. Загрузка и объединение всех CSV-файлов из `kaggle/input/`.
2. Добавление фактических результатов завершённых туров сезона 26/27 из `results.py`.
3. Предобработка: отбор признаков, кодирование названий команд (`LabelEncoder`), взвешивание образцов по дате (экспоненциальное затухание с коэффициентом `0.98`).
4. Добавление признаков команд: средняя забитых/пропущенных голов, процент побед, разница мячей, форма команд, head-to-head статистика для 3 окон (5, 10, 20 матчей) — всего 59 признаков.
5. Разделение на обучающую и тестовую выборки (80/20).
6. Обучение `RandomForestClassifier` (1000 деревьев) для классификации результата: H (победа хозяев), D (ничья), A (победа гостей).
7. Оценка модели: Accuracy и Classification Report на тестовой выборке.
8. Предсказание результата для матчей тура 10 сезона 26/27 из `match_days_2627` в `match_days.py` с вероятностями каждого исхода.

## Метрики модели

При оценке качества предсказаний используются метрики классификации:

| Метрика | Описание | Идеальное значение |
|---------|----------|-------------------|
| **Accuracy** | Доля правильно предсказанных результатов (H/D/A) от общего числа матчей. | 1.0 (100%) |
| **Precision** | Доля точных предсказаний для каждого класса: сколько из предсказанных побед хозяев действительно стали победами. | 1.0 (100%) |
| **Recall** | Доля найденных реальных событий для каждого класса: сколько из всех побед хозяев модель правильно предсказала. | 1.0 (100%) |
| **F1-score** | Среднее гармоническое Precision и Recall для каждого класса. | 1.0 (100%) |

> **Примечание:** классификация футбольных результатов — нетривиальная задача. Базовый уровень (предсказание самого частого класса — победы хозяев) даёт ~44% accuracy. Модель с `class_weight='balanced'` достигает ~45-48% accuracy, что выше базового уровня. Ничьи (D) предсказываются хуже всего из-за их относительно низкой частоты (~24%), но параметр `class_weight='balanced'` помогает улучшить их распознавание.

### `app.py` — FastAPI веб-приложение

Веб-сервер, который запускает тот же ML-конвейер, что и консольный скрипт, и отдаёт результаты в виде HTML-страницы. Модель кэшируется после первого запроса, поэтому последующие загрузки страницы происходят мгновенно.

| Компонент | Описание |
|-----------|----------|
| `run_prediction_pipeline()` | Полный конвейер: загрузка данных, предобработка, обучение модели, предсказание следующего тура. Результат кэшируется в `prediction_cache`. |
| `GET /` | Главная страница — рендерит `templates/index.html` с предсказаниями, точностью модели и сворачиваемыми деталями. |

### `templates/index.html` — HTML-шаблон

Тёмная тема с карточками матчей, визуальными полосами вероятностей (Home / Draw / Away) и сворачиваемым блоком **📊 Model Details & Statistics** с classification report, распределением классов, списком фичей и статистикой данных.

### `bundesliga_prediction.py` — Точка входа (консоль)

Основной скрипт, который оркеструет весь конвейер предсказаний: загрузка данных, предобработка, построение признаков, обучение модели и предсказание результатов следующего тура. Вызывает функции из пакета `predict_bundesliga` последовательно, формируя полный pipeline.

### `predict_bundesliga/` — Основной пакет

Пакет содержит модули, реализующие этапы ML-конвейера. Публичный API экспортируется через `__init__.py`.

#### `data_loader.py` — Загрузка и предобработка данных

| Функция | Описание |
|---------|----------|
| `read_and_concat_files(directory)` | Рекурсивно находит и объединяет все CSV-файлы из указанной директории с прогресс-баром (`tqdm`) |
| `load_results_dataframes()` | Загружает DataFrame с результатами завершённых туров сезона 26/27 из модуля `results` |
| `preprocess_dataframe(df)` | Отбирает только релевантные колонки: `FTHG`, `HTHG`, `FTAG`, `HTAG`, `FTR`, `HTR`, `HomeTeam`, `AwayTeam`, `Date` |

#### `features.py` — Построение признаков команд

Ключевой модуль для feature engineering. Создаёт 59 признаков на основе статистики команд.

| Компонент | Описание |
|-----------|----------|
| `MatchResult` | Перечисление возможных результатов: `H` (победа хозяев), `D` (ничья), `A` (победа гостей) |
| `WindowFeatures` | Dataclass с признаками для одного окна: средняя голов, процент побед, разница мячей, форма, combined-статистика, разница силы команд |
| `H2HFeatures` | Dataclass с head-to-head признаками: средняя голов хозяев/гостей и количество матчей |
| `WINDOWS` | Размеры скользящих окон: `[5, 10, 20]` матчей |
| `get_team_stats()` | Статистика команды в заданном окне: средние голы, процент побед/ничьих/поражений, разница мячей, форма |
| `build_window_features()` | Признаки для одного окна: статистика хозяев дома, гостей в гостях, combined-статистика, разница силы |
| `build_h2h_features()` | Head-to-head статистика по последним 5 встречам двух команд |
| `build_features()` | Все признаки для одного матча: 3 окна × 18 признаков + 3 H2H-признака = **59 признаков** |
| `add_team_features()` | Добавляет признаки ко всему DataFrame, перебирая матчи по дате с прогресс-баром |

#### `model.py` — Обучение и оценка модели

| Функция | Описание |
|---------|----------|
| `prepare_features(df)` | Кодирование названий команд (`LabelEncoder`), формирование матрицы признаков `X` и целевого вектора `y` |
| `train_random_forest()` | Обучение `RandomForestClassifier`: 1000 деревьев, глубина 15, `class_weight='balanced'`, взвешивание по дате |
| `evaluate_model()` | Расчёт Accuracy и Classification Report (Precision, Recall, F1-score по классам H/D/A) |

#### `predictor.py` — Предсказание результатов матчей

| Компонент | Описание |
|-----------|----------|
| `PredictionContext` | Dataclass-контейнер для объектов предсказания: `label_encoders`, `model`, `df_full`, `feature_cols` |
| `predict_result()` | Предсказание результата (H/D/A) с вероятностями для конкретной пары команд |
| `format_prediction()` | Форматирование результата для вывода: `"1. Bayern Munich vs Stuttgart: Bayern Munich win (H:65.2% D:18.3% A:16.5%)"` |

### `results.py` — Результаты сезона 26/27

Содержит DataFrame для каждого завершённого тура сезона 26/27 (`results_d1`, `results_d2`, …) с фактическими результатами матчей. Каждый DataFrame включает: команды хозяев и гостей, голы (полный матч и первый тайм), результаты (FTR, HTR) и даты. Используется для дополнения обучающей выборки актуальными данными.

### `match_days.py` — Расписание сезона 26/27

Словарь `match_days` с расписанием всех 34 туров сезона 26/27. Каждый тур содержит словарь матчей с командами хозяев (`H`) и гостей (`A`). Скрипт автоматически определяет следующий тур для предсказания на основе количества загруженных результатов из `results.py`.

## Обновление данных после каждого тура

### Быстрый способ: интерактивный скрипт

После завершения тура запустите один скрипт — он сам обновит все файлы:

```bash
python3 update_results.py
```

Скрипт автоматически определит следующий тур, покажет пары матчей и попросит ввести:

1. **Счёт полного матча** (например `2-1`)
2. **Счёт 1-го тайма** (например `1-0`)
3. **Дату матча** (например `29/11/26`)

После ввода всех матчей скрипт покажет сводку и запишет результаты в `results.py` и `data_loader.py`.

Затем перезапустите сервер:

```bash
# Остановите сервер (Ctrl+C в терминале)
# Затем запустите снова:
python3 app.py
```

Приложение автоматически покажет предсказания для следующего тура (N+1).

### Ручной способ

Если нужно обновить данные вручную, выполните три шага.

#### Шаг 1. `results.py` — добавить результаты нового тура

В конец файла (перед `results_empty`) добавьте новый DataFrame. Например, после тура 11:

```python
results_d11 = pd.DataFrame({
    "HomeTeam": [...],  # хозяева (9 матчей)
    "AwayTeam": [...],  # гости
    "FTHG": [...],      # голы хозяев (полный матч)
    "FTAG": [...],      # голы гостей (полный матч)
    "HTHG": [...],      # голы хозяев (1-й тайм)
    "HTAG": [...],      # голы гостей (1-й тайм)
    "FTR": [...],       # результат: 'H', 'D', 'A'
    "HTR": [...],       # результат 1-го тайма: 'H', 'D', 'A'
    "Date": [...]       # даты в формате 'DD/MM/YY'
})
```

**Источники данных:**
- Расписание матчей: `match_days.py` (тур N)
- Результаты: [sports.ru](https://www.sports.ru/football/tournament/bundesliga/calendar/), [bundesliga.com](https://www.bundesliga.com), YouTube-хайлайты

#### Шаг 2. `predict_bundesliga/data_loader.py` — зарегистрировать новый DataFrame

В функции `load_results_dataframes()` добавьте новый DataFrame в список:

```python
def load_results_dataframes():
    return [results.results_d1, ..., results.results_d10, results.results_d11]
```

#### Шаг 3. Перезапустить сервер

```bash
# Остановите сервер (Ctrl+C в терминале)
# Затем запустите снова:
python3 app.py
```

Приложение автоматически покажет предсказания для следующего тура (N+1).
