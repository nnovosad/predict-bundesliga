# Bundesliga Match Predictor

Прогнозирование результатов матчей Бундеслиги с помощью машинного обучения (Random Forest).

## Описание

Проект обучает модель `RandomForestClassifier` на исторических данных Бундеслиги (сезоны 1993/94 — 2026/27) и предсказывает результат предстоящих матчей: победа хозяев (H), ничья (D) или победа гостей (A), вместе с вероятностями каждого исхода.

## Данные

- **kaggle/input/** — CSV-файлы с историческими результатами матчей Бундеслиги за сезоны 93-94 — 25-26 (источник: [Kaggle](https://www.kaggle.com/datasets/rohanrao/german-bundesliga-18912019) для сезонов 93-94 — 21-22, [football-data.co.uk](https://football-data.co.uk) для сезонов 22-23 — 25-26).
- **results.py** — результаты 9 туров сезона 26/27 (данные перенесены из CSV).
- **match_days.py** — расписание матчей сезона 23/24 (34 тура) и 26/27 (полный календарь 34 туров, источник: [sports.ru](https://www.sports.ru/football/tournament/bundesliga/calendar/)).

| `FTR` | Итоговый результат (H/A/D) |
| `HTR` | Результат первого тайма (H/A/D) |

## Как это работает

1. Загрузка и объединение всех CSV-файлов из `kaggle/input/`.
2. Добавление фактических результатов 9 туров сезона 26/27 из `results.py`.
3. Предобработка: отбор признаков, кодирование названий команд (`LabelEncoder`), взвешивание образцов по дате (экспоненциальное затухание с коэффициентом `0.98`).
4. Добавление признаков команд: средняя забитых/пропущенных голов, процент побед, разница мячей, форма команд, head-to-head статистика для 3 окон (5, 10, 20 матчей) — всего 59 признаков.
5. Разделение на обучающую и тестовую выборки (80/20).
6. Обучение `RandomForestClassifier` (1000 деревьев) для классификации результата: H (победа хозяев), D (ничья), A (победа гостей).
7. Оценка модели: Accuracy и Classification Report на тестовой выборке.
8. Предсказание результата для матчей тура 10 сезона 26/27 из `match_days_2627` в `match_days.py` с вероятностями каждого исхода.

## Метрики модели

При оценке качества предсказаний используются метрики классификации:

| Метрика | Описание | Идеальное значение |
|---------|----------|-------------------|
| **Accuracy** | Доля правильно предсказанных результатов (H/D/A) от общего числа матчей. | 1.0 (100%) |
| **Precision** | Доля точных предсказаний для каждого класса: сколько из предсказанных побед хозяев действительно стали победами. | 1.0 (100%) |
| **Recall** | Доля найденных реальных событий для каждого класса: сколько из всех побед хозяев модель правильно предсказала. | 1.0 (100%) |
| **F1-score** | Среднее гармоническое Precision и Recall для каждого класса. | 1.0 (100%) |

> **Примечание:** классификация футбольных результатов — нетривиальная задача. Базовый уровень (предсказание самого частого класса — победы хозяев) даёт ~44% accuracy. Модель с `class_weight='balanced'` достигает ~45-48% accuracy, что выше базового уровня. Ничьи (D) предсказываются хуже всего из-за их相对较低ой частоты (~24%), но параметр `class_weight='balanced'` помогает улучшить их распознавание.
